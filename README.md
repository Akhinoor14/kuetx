## 📚 ডকুমেন্টেশন — নিয়ম (সবসময় মানতে হবে)

এই প্রজেক্টের **সব `.md` ডকুমেন্টেশন ফাইল `documentation/` ফোল্ডারের
ভেতরে, ক্যাটাগরি-ওয়াইজ সাজানো সাবফোল্ডারে থাকে।** এই root README আর
`documentation/README.md` (ইনডেক্স) ছাড়া, প্রজেক্টের **আর কোথাও কোনো
`.md` ফাইল থাকবে না** — root-এ না, `archive/`-এ না, `docs/`-এ না,
`src/` বা অন্য কোনো কোড ফোল্ডারেও না।

### এখন থেকে যত কাজ হবে, তার নিয়ম

- **প্রতিটা ফিচার/ক্যাটাগরির জন্য একটাই active ফাইল — `CURRENT.md`।**
  নতুন কাজ/বাগফিক্স/আপডেট হলে নতুন `.md` ফাইল না বানিয়ে সংশ্লিষ্ট
  ফোল্ডারের `CURRENT.md`-টাই এডিট করতে হবে।
- সেই `.md` ফাইল কখনো root-এ বা এলোমেলোভাবে কোনো কোড ফোল্ডারে রাখা
  যাবে না — সবসময় `documentation/` ফোল্ডারের ভেতরে, সঠিক
  ক্যাটাগরি/সাবফোল্ডারে রাখতে হবে।
- পুরনো/superseded তথ্য ডিলিট না করে `documentation/00-old-data/`-এ
  (একই ক্যাটাগরি-স্ট্রাকচার মিরর করে) সরিয়ে রাখতে হবে।
- এভাবে এই প্রজেক্টে একটা পূর্ণাঙ্গ, পরিষ্কার documentation ফর্ম
  বজায় থাকবে — কোনো কাজের রেকর্ড হারাবে না, আবার ফাইল সংখ্যাও
  বেহিসেবি বাড়বে না।
